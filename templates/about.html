About Alumni Hub

Alumni Hub is a web application that connects the students, alumni and faculty members of a college on a single platform. Students can find and connect with alumni for guidance, alumni can share job openings from their companies, and faculty can post announcements for everyone.

Main Modules
  • User Management - registration, login and role-based access (Student / Alumni / Faculty / Admin)
  • Profiles - every member has a profile with photo, skills and role-specific details
  • Connections - send, accept and reject connection requests
  • Messaging - simple one-to-one chat between members
  • Job Portal - alumni post jobs, students apply, alumni manage applicants
  • Announcements & Notifications - faculty announcements and activity alerts
  • Admin Panel - user and job management with basic statistics
Technology Used

Python Flask SQLite Jinja2 Bootstrap 5 JavaScript

This project was developed as an MCA Minor Project.
